# Security Policy

We take security seriously at RND-PRO and are committed to ensuring the safety of the `symbiote-node` library and its users. This document outlines our policy for reporting and resolving security vulnerabilities.

## Supported Versions

We actively support and patch the following versions of `symbiote-node`:

| Version | Supported | Notes |
|---------|-----------|-------|
| 0.3.x   | Yes       | Active development & pre-release |
| 0.2.x   | Yes       | Active support & critical patches |
| < 0.2.0 | No        | Please upgrade to the latest version |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please **do not report it publicly** through GitHub issues, pull requests, or public discussions. Instead, report it privately to our security team.

### Contact Information
Please send your security reports to: **security@rnd-pro.com**

To help us investigate and resolve the issue quickly, please include as much of the following information as possible:
- A detailed description of the vulnerability and its potential impact.
- Step-by-step instructions (or a minimal proof-of-concept script/markup) to reproduce the issue.
- Details of the environment where the issue was observed (Node.js version, browser, OS, package version).
- Any potential mitigations or workarounds you are aware of.

We encourage you to encrypt sensitive security reports or communications using a secure method.

## Disclosure Process

Once a vulnerability is reported, our security team will:
1. **Acknowledge Receipt**: We will acknowledge receipt of your report within 24 to 48 hours.
2. **Evaluation & Triage**: We will investigate and verify the vulnerability, determining its severity and impact.
3. **Internal Mitigation**: We will develop a fix or mitigation strategy.
4. **Coordinated Release**: We will publish a patched version on npm and coordinate a public release/advisory.
5. **Attribution**: If you wish, we will gladly credit you for the responsible disclosure in our release notes or security advisories.

Thank you for helping us keep `symbiote-node` secure!
