# symbiote-node

`symbiote-node` is now a terminal migration package.

Use `symbiote-ui` for Web Components, provider manifests, themes, schemas, WebMCP metadata, and JSDA SSR integration.

Use `symbiote-engine` for graph runtime execution, CLI runtime commands, server helpers, registry, persistence, and handlers.

## Related Packages
